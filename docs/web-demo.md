# Trang web demo (trình diễn — không phải phần được chấm)

- Chạy: `python web_demo.py` rồi mở http://localhost:8000
- Trang web gọi đúng `codebase/agent.py` và `data/progress.json` như bản dòng lệnh `python run.py`.
- Dùng ở Demo Zone để giám khảo gõ câu hỏi trực tiếp; khi mạng/model lỗi thì quay về bản dòng lệnh + video dự phòng.
- Không nối Discord thật hay hệ thống thật nào của khóa.
